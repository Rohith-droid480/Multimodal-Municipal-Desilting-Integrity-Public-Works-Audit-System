# MuniAudit-AI Coding Governance

Use these two files as scoped engineering governance:

- `.agents/rules/20-code-architecture-standards.md` — code structure, coding standards, dependency direction, backend/ML/frontend/database conventions.
- `.agents/rules/21-testing-validation.md` — task verification, milestone gates, manual validation, cross-tool review, release criteria.

Keep the project-specific facts in `CORE_CONTEXT.md` and `ARCHITECTURE.md`. Keep current state in `PROJECT_STATE.json`.

Operating principle:

OBSERVE → UNDERSTAND → PLAN → IMPLEMENT → TEST → REVIEW → VALIDATE → RECORD.
